🕒 Turn Flow

  • Both players plan simultaneously — there are no waiting turns.
  • Each turn lasts 60 seconds. Press ⏩ to fast-forward when both sides are ready.
  • Only one order per unit per turn. A second submission is rejected (DUPLICATE_UNIT_ORDER).
  • The first 3 turns are a setup phase — Nazgul detection is suppressed.
  • Game ends in a draw after 40 turns with no winner.

🗺️ Movement & Routes

  • Select a unit and choose ASSIGN_ROUTE — chain multiple paths together.
  • Units auto-advance one step along their route every turn end.
  • Use REDIRECT_UNIT to switch course mid-journey.
  • Path status (OPEN / THREATENED / BLOCKED / TEMPORARILY_OPEN / surveilled) is shown when you pick a path in the order dropdown — the highlighted dashed circle on the map marks the target.

⚔️ Combat

  • Total attacker strength vs total defender strength.
  • Leadership: a leader (Aragorn, Witch-King) gives +1 to every other ally in the same region.
  • Fortress terrain → defender +2. Mountains → defender +1.
  • Fortification (Gondor Army) → another +2 on top.
  • Uruk-hai ignore fortress terrain bonus when attacking — but fortification still counts.
  • Tie or defender wins ⇒ each attacker loses 1 strength.
